Why this accent

Ink blue is the colour of a fountain pen, which suits a blog by a single writer. It stays clear of red-600, green-600 and yellow-600 (errors, success, warnings), so an accent never reads as a status. At 600 it reaches 6.2:1 on white and 5.7:1 on the 50 tint, so one step serves links, focus ring and ranking numbers. It is used only for links, category labels, active states, the Encadré, the subscription block and the ring.

Rules of use

Never as a background for body text, never on the navbar, never more than one accent-filled element per viewport. Buttons stay monochrome. The tint 50 is the only accent surface, and only for the Encadré and the subscription block.

Article body · Newsreader 400 · 20 / 1.7 · column 608 px

Il suffit d’écouter une conversation de taxi-be ou de marché pour comprendre que la démocratie, chez nous, ne se joue pas seulement dans les urnes. Elle se joue dans les petits arrangements du quotidien : l’eau qui revient, le courant qui saute, la promesse que l’on relit une fois le scrutin passé.

Article body: serif, not Inter

A personal opinion column reads best in a text serif: the page feels like a column, not an interface, and the italic does real work. Inter keeps every non-prose element (tables, captions, buttons), so prose and UI are told apart at a glance. The cost is one extra italic file and a weight cap of 400 / 600.

Measure

608 px column ≈ 68 characters per line at 20 px (65 to 72 target). Desktop 20 / 1.7, tablet and mobile 18 / 1.65 (18 px is inside the 17 to 18 mobile range and keeps 38 characters per line at 328 px). Header block 840 px, cover 1120 px.
