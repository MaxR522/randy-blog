# Design boards (reference only)

These 21 `.dc.html` files are the artboards exported from the Claude Design canvas "Randy Donny — design system public". They are **source references**, not pages to serve: they load a runtime script (`support.js`) that is not included, so they will not render standalone. Open them in an editor and read the markup: every value (font size, spacing, colour, copy) is in the inline styles.

| Group | Files |
|---|---|
| System | `Fondations`, `Tokens`, `Decisions` |
| Components | `Composants-Navigation`, `Composants-Cartes`, `Composants-Article`, `Composants-Abonnement`, `Confirmations` |
| Pages 1440 | `Accueil`, `Article`, `Auteur`, `Recherche`, `Recherche-vide`, `Page-404` |
| Pages 360 | `Accueil-360`, `Article-360`, `Auteur-360`, `Recherche-360`, `Page-404-360` |
| Email | `Newsletter` (600), `Newsletter-360` |

The live, visual version is on the Claude canvas (open it from your Claude account; it is private to you). If you edit the design there later, re-export the boards and replace this folder.
Image slots are flat placeholders; the icons for Facebook, X, LinkedIn and YouTube are stand-ins.
